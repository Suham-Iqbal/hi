🔔 Unread Message Counter Test

How the Unread Message Counter Works:

  1. User opens messaging app → App checks for unread messages
  2. Unread message counter → Shows number at top of messages section
  3. Dynamic updates → Number changes automatically when:
    • New message arrives (number increases)
    • You read a message (number decreases)
  4. Purpose → Quick overview of unread messages without checking each chat
